# 🤖 AI vs Human Image Classification

![Python](https://img.shields.io/badge/Python-3.9%2B-blue?style=for-the-badge&logo=python)
![TensorFlow](https://img.shields.io/badge/TensorFlow-2.x-orange?style=for-the-badge&logo=tensorflow)
![Streamlit](https://img.shields.io/badge/Streamlit-FF4B4B?style=for-the-badge&logo=streamlit)

A powerful computer vision web application designed to detect whether an image was generated by Artificial Intelligence (AI) or captured by a human. Powered by **Deep Learning** (TensorFlow/Keras) and deployed using an interactive **Streamlit** interface.

## 🚀 Live App
Try the application on Streamlit Community Cloud:
**[View App](https://ai-human-content-classification-cv.streamlit.app)**

---

## 📋 Key Features

* **🔍 Dual Detection Support**:
    * **File Upload**: Analyze images directly from your local device (Drag & Drop).
    * **Instagram Integration**: Input a public Instagram post URL, and the app will automatically fetch and analyze the image (using `instaloader`).
* **🧠 Deep Learning Core**: Utilizes a trained Neural Network model optimized to detect subtle AI artifacts.
* **📊 Detailed Analysis**: Provides an instant prediction with a **Confidence Score** (Probability Percentage).
* **⚡ Real-time Processing**: Fast image processing pipeline with automatic resizing and normalization.

## 💻 Installation & Setup

Follow these steps to run the project locally on your machine.

### 1. Clone the Repository
```bash
git clone [https://github.com/mewcurryy/AI-or-Human-Content-Classification_CV.git](https://github.com/mewcurryy/AI-or-Human-Content-Classification_CV.git)
cd AI-or-Human-Content-Classification_CV
```

### 2. Set Up Virtual Environment (Recommended)
This ensures dependencies do not conflict with other projects.

**Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

**Mac/Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Install Dependencies
Install all required libraries (Streamlit, TensorFlow, etc.):
```bash
pip install -r requirements.txt
```

### 4. Setup Model File
⚠️ **Important:** Ensure you have the trained model file (e.g., `model.h5` or `best_model.keras`).
1. Place your model file inside the `models/` folder (or root directory).
2. Verify that the path in `app.py` matches your file name:
   ```python
   # Inside app.py
   model = load_keras_model('models/your_model_name.keras')
   ```

### 5. Run the Application
Start the Streamlit server:
```bash
streamlit run app.py
```

Once running, your browser should automatically open:
👉 **http://localhost:8501**

## 📖 Usage Guide

### Option 1: Upload Image
1. Select the **"Upload Image"** section.
2. Click **Browse files** or Drag & Drop an image.
3. Supported formats: `JPG`, `JPEG`, `PNG`.
4. The app will preprocess the image and display the prediction (AI or human).

### Option 2: Instagram Link
1. Copy the URL of a **Public Instagram post**.
2. Paste the link into the **"Paste Instagram Link"** field.
3. The app will extract the image and run the classification model.
